# Dependencies of the SIDECAR — the Django process inside the desktop app (Р5.3, ADR-001 §2).
#
# Three packages are absent from this list on purpose, and each was checked by fact rather
# than crossed off a list:
#
#   boto3 / botocore  (21 MB)  The sidecar never signs an S3 request. It PUTs a pupil's file
#                              to a presigned URL the SERVER minted — an ordinary HTTPS
#                              request (apps/meetingpoint/transfer.py). The bytes still go
#                              straight to object storage, so CLAUDE.md §5 holds; only the
#                              SDK is unnecessary. test_desktop_runtime.py runs the whole
#                              mirror path in a subprocess and asserts boto3 never loads.
#   redis / channels-redis (5 MB)  One process on one machine: the channel layer is in-memory
#                              (config/settings_desktop.py). Redis would be a second thing to
#                              install for a queue with a single reader.
#   psycopg[binary]  (16 MB)   The cabinet is SQLite.
#
# Celery was never a direct dependency — it arrives under channels-redis and leaves with it.
#
# Kept in step with requirements.txt by hand, deliberately: a desktop bundle that silently
# grows a dependency is a desktop bundle nobody notices growing.
#
# 📈 Р5.5 added ONE back, and this is the record of why: `cryptography` (~12 MB) seals the
# cabinet file. §19.1 требует, чтобы копия шифровалась на машине преподавателя, а сервер
# держал непрозрачный блок — это AES-GCM, и рукописной криптографии здесь не будет. Двенадцать
# мегабайт за то, чтобы работы и оценки детей на потерянном внешнем диске не читались, —
# сделка, которую стоит заключить.

Django>=5.0,<5.2
# 📈 15.08: `django-cors-headers` (~30 КБ) вернулся вместе с прод-контуром — он в INSTALLED_APPS
# общих настроек, и без него sidecar не поднимается вовсе (поймано на пересборке).
#
# Выкидывать его из десктопного профиля было бы неверно и по существу: страница внутри

# РАЗНЫЕ источники, и в тот день, когда комната урока пойдёт на свой sidecar, предполётный
# запрос упрётся ровно сюда. Тридцать килобайт против отладки этого в живом уроке.
