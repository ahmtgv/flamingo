# Посредник «Источников мира» — hub.flamingo.plus

Три четверти источников запрещают показывать себя внутри чужой страницы. Через
посредник такой источник открывается в «Источниках мира» настоящим сайтом — в
браузере самого человека. Что и почему устроено так — в начале `server.mjs`.

## Запуск

```
npm ci --omit=dev
node server.mjs          # слушает 127.0.0.1:8031
```

Настройки — переменными окружения; значения по умолчанию годятся для боевого:

| переменная | по умолчанию | что это |
|---|---|---|
| `HUB_PROXY_PORT` | `8031` | порт |
| `HUB_PROXY_BIND` | `127.0.0.1` | на каком адресе слушать |
| `HUB_PROXY_ORIGIN` | `https://hub.flamingo.plus` | наш адрес; тоннель открыт только страницам отсюда |
| `HUB_PROXY_PARENTS` | `https://flamingo.plus https://www.flamingo.plus` | кому можно вставлять нас в рамку |
| `HUB_PROXY_AUTH` | `http://127.0.0.1:8000` | сервер учётных записей: у него спрашиваем, вошёл ли человек |
| `HUB_PROXY_AUTH_HOST` | `api.flamingo.plus` | под каким именем этот сервер нас ждёт |
| `HUB_PROXY_SOURCES` | `../backend/common/хаб-источники.json` | каталог источников |

`HUB_PROXY_TEST=1` — пробный режим для прибора: без входа и с доступом к своему
же компьютеру. **На боевом не ставить.**

## Прибор

```
node прогон.mjs
```

Нужен Playwright с хромом; гоняется там, где ведётся разработка.

изменений. Список и адреса исходников — `public/о-движке.txt` (он же виден
снаружи: `https://hub.flamingo.plus/о-движке.txt`).
