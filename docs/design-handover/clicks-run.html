Прогон 19: нажми всё и сравни снимки

Восемнадцать приборов меряют картинку и мёртвую кнопку не видят. Этот проход нажимает каждый интерактивный элемент внутри кадра и валится, если после нажатия в кадре не изменилось ничего; затем щёлкает по случаям служебной полосы и требует, чтобы два разных имени дали два разных снимка. Кнопка вправе молчать, если молчание объявлено словами: data-still="почему". Каждому проходу даётся свежий кадр — прибор состояние не восстанавливает.
