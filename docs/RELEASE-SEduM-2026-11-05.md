# Главная и SEduM — публикация 05.11.2026

Владелец подтвердил `/` и `/sedum/` и разрешил исполнителю публикацию в `v1`.
База перед публикацией: `45d1c63e67a2355710e22b42c119b64b8f0cfe00`.
Удалённая ветка `main` не меняется. Бэкенд и данные исследования не меняются.

Главная перенесена из утверждённого локального предпросмотра. Значения CSS
механически вынесены в токены без изменения макета; проверки не отключались.
Ссылка SEduM — `/sedum/`, а не loopback. SEduM размещается отдельной статической
страницей с локальными шрифтами, иллюстрациями и моделью CMF. Кнопки участия
открывают существующую общую ссылку исследования из `App.tsx`.

Проверено до публикации:

- TypeScript без генерации кеша в общей папке зависимостей;
- полный `npm run guards`;
- production `vite build` с `VITE_AUTH_URL=https://api.flamingo.plus`;
- самопроверка и проверка `scripts/сборка-check.mjs`;
- Chrome: главная → SEduM → существующее исследование;
- 81 ширина главной, две темы, фирменные шрифты, интервалы, фокус видео;
- 5 ширин SEduM, четыре модуля, картинки, отсутствие локальных 404;
- CMF worker: загрузка модели и обработка синтетического портрета без камеры пользователя.

Safari, физические камеры и реальные операции с аккаунтами не проверялись.
Полная неизменность остальных пользовательских сценариев этими проверками не доказана.

`rollback/v1-before-sedum-20261105`, только после проверки текущей удалённой ссылки
и с защитой от перезаписи параллельного релиза. Затем дождаться пересборки Pages.
