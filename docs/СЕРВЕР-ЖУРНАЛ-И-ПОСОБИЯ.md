| | |
|---|---|

| Прибор | `backend/study/прогон.py` — 64 проверки, отдельная база в `/tmp` |

## Шаг 1. Забрать код

```
cd /opt/flamingo
git pull
cd backend
.venv/bin/pip install -r requirements.txt
```

## Шаг 2. Место под пособия

```
sudo mkdir -p /var/lib/flamingo/materials
sudo chown -R <пользователь-под-которым-работает-gunicorn> /var/lib/flamingo
sudo chmod 750 /var/lib/flamingo/materials
```

⚠️ **Не кладите пособия внутрь `/opt/flamingo`.** `git pull` не должен ни видеть
чужие файлы, ни тем более их трогать.

## Шаг 3. Настройки

Дописать в `/opt/flamingo/backend/.env`:

```
MEDIA_ROOT=/var/lib/flamingo/materials
MATERIAL_MAX_MB=64
MATERIALS_MAX_GB=5
```

Числа: один файл до 64 МБ, всё вместе у одного преподавателя до 5 ГБ.
На 69 свободных ГБ это десяток преподавателей с запасом.

⚠️ **Выше 64 МБ поднимать нельзя без разговора.** Бесплатный тариф Cloudflare
режет тело запроса на **100 МБ**, и файл больше этого не доедет до сервера
вовсе — человек увидит ошибку Cloudflare, а не наши слова.

## Шаг 4. Таблицы

```
cd /opt/flamingo/backend
.venv/bin/python manage.py migrate
```

## Шаг 5. Пропустить загрузку через nginx

В блоке `server` для `api.flamingo.plus`:

```
client_max_body_size 96m;
```

Без этой строки nginx отрежет презентацию на 20 МБ своим 413 — и снова
человек увидит чужой отказ вместо наших слов.

## Шаг 6. Перезапустить и проверить

```
sudo systemctl restart flamingo
.venv/bin/python study/прогон.py
```

Прибор работает на отдельной базе в `/tmp` и на отдельной папке пособий:
боевые данные не трогает и трогать не может. Ждём `✅ всё сходится · проверок 64`.

## Шаг 7. Сказать фронту, где сервер

Cloudflare Pages → проект → Settings → Environment variables:

```
VITE_AUTH_URL = https://api.flamingo.plus
```

и пересобрать. Пока переменной нет, продукт работает как раньше: занятия живут
в браузере, журнал недоступен, и кабинет говорит об этом словами.

## Что теперь надо беречь

Раньше терялась только база. Теперь **два** места, и они теряются порознь:

| Что | Где | Чем спасать |
|---|---|---|
| Люди, занятия, журнал | `/var/lib/flamingo/flamingo.sqlite3` | копия файла |
| Пособия | `/var/lib/flamingo/materials/` | копия папки |

Копия одной базы без папки даст журнал, в котором у каждого урока «файл не
найден на диске». Копия папки без базы — гору файлов без имён и хозяев.
**Снимайте обе вместе.**

## Чего сервер НЕ делает и делать не будет

**Не хранит видео.** Отказ говорит это словами и предлагает ссылку. Час записи —
это гигабайты, а раздача без CDN упирается в канал сервера на третьем зрителе.

**Не ищет людей по почте и телефону.** Ученик приходит по одноразовой ссылке.
Поиск по справочнику — это способ перебором собрать базу почт наших учеников,
и его нет намеренно (решение владельца 01.09).

**Не принимает `.svg` и `.html`.** Это исполняемая разметка: отданная браузеру
с нашего домена, она получила бы права нашей же страницы.
