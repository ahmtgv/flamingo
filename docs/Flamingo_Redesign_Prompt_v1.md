# Flamingo — Redesign Prompt v1 (R&D-сессия «UI/UX 2026»)

**Дата:** 2026-07-03 · **Статус:** R&D, направление на утверждении владельца (Адель)
**Назначение:** рабочий промпт, который ИИ-разработчик использует при редизайне ЛЮБОГО экрана/компонента нашего проекта, + обоснование выбранных тенденций. После утверждения направления правила из §3 переносятся в `tokens.css` v2 и `.claude/skills/flamingo-design`.

## 1. Выбранное направление: «Тёплый редакционный минимализм» (warm editorial minimalism)

Не смена бренда, а эволюция существующей системы (тёплый графит + один коралловый акцент). Логика отбора тенденций: берём только то, что (а) актуально в 2026, (б) не устареет, потому что опирается на фундаментальные вещи — типографику, ритм, контраст, сдержанность, (в) служит нашим инвариантам: долгое чтение без усталости глаз, «support not surveillance» в CMF, возрастная адаптация 7+–взрослые, WCAG 2.1 AA, токены-без-литералов.

### Принятые тенденции (тренд → как применяем у нас)

1. **Typography-led hierarchy (редакционная типографика).** Иерархия делается размером/весом/ритмом шрифта и воздухом, а не рамками и заливками. Крупные спокойные заголовки (`--text-display` до 52–56 на десктопе, tracking-tight), лид-абзацы, увеличенные табличные цифры для метрик (внимание, оценки, прогресс) как главные «герои» дашбордов. Неустаревающее ядро направления.
2. **Space over chrome (воздух вместо коробок).** Убираем «суп из карточек»: секции разделяются white space и hairline-линиями, карточка остаётся только там, где объект реально кликабелен/отделим (курс в каталоге, видео-тайл). Меньше вложенных поверхностей — меньше визуального шума.
3. **Монохром + экономика одного акцента — на всё приложение.** Дисциплина, уже принятая для SEduM-UI (графит, акцент = только «нужно действие», всегда с текстом), распространяется на каталог, кабинеты, домашки. Это наш самый «неустаревающий» ход: сдержанный акцент не выходит из моды.
4. **Мягкая глубина вместо плоскости и вместо стекла.** Hairline-борта + двухслойные тёплые тени только у плавающего/интерактивного (меню, модалки, hover карточки). Glassmorphism — ЗАПРЕЩЁН всюду, кроме единственного санкционированного места: frosted-оверлеи поверх живого видео (AttentionStrip) — там он функционален.
5. **Спокойная дата-визуализация.** Тонкие спарклайны, точечные сетки, fill-метры (грамматика `Meter` сохраняется), никакого chart junk, никаких светофоров. Значение — крупной табличной цифрой, контекст — текстом.
6. **Микро-взаимодействия на токенах движения.** 120–320 ms, `--ease-standard`, только opacity/width/scale; skeleton-состояния вместо спиннеров; позиции элементов стабильны при live-обновлениях (правило орбов). Reduced-motion — нулевые длительности (уже в токенах).
7. **Авто-тема.** `prefers-color-scheme` как дефолт + ручной переключатель (сейчас только ручной `data-theme`). Тёмная тема — тёплый графит, не чёрный; паритет контраста AA.
8. **Возрастная адаптация как система, не как «детский скин».** Kids-режим = те же токены с большими значениями (уже есть) + контентный уровень: меньше слов, крупнее иконки, приглушённые предметные цвета только как теги-подписи. Подростки/взрослые — базовая плотность.
9. **Доступность как эстетика.** Видимый фокус-ринг, AA-контраст (тело — стремимся к AAA 7:1 на канве), полная клавиатурная операбельность, sentence case для кириллицы. Это не «санитарный минимум», а часть визуального языка.
10. **Иконография одной линии.** lucide, единый stroke 1.75, размер из токенов; без залитых/дуотоновых иконок.

### Анти-список (модно сейчас — состарится быстро; НЕ применяем)

Neobrutalism и «намеренно сырые» схематичные интерфейсы; aurora/mesh-градиенты и «AI-фиолетовый» со звёздочками; тяжёлый glassmorphism/fractured glass как декорация; 3D-блобы и метаболы; bento-сетка ради bento (используем сетку только там, где контент реально модульный — дашборд «Сегодня»); неоморфизм; параллакс-шоу; геймификация конфетти поверх учебного процесса. Обоснование: всё это декорирует, а не проясняет, и противоречит принципу долгого чтения и спокойного CMF-тона.

## 2. РАБОЧИЙ ПРОМПТ (использовать при редизайне каждого экрана)

> Ты редизайнишь экран `<ИМЯ>` нашего проекта Flamingo (B2C-образование, RU, возраст 7+–взрослые) в направлении «тёплый редакционный минимализм».
>
> **Жёсткие инварианты (нарушать нельзя):** только семантические токены из `tokens.css` (никаких hex/px, кроме санкционированных 1px hairline / 2px ring / blur-эффектов — флаговать в коммите); все строки через i18n `ru/*.json`; WCAG 2.1 AA (фокус-ринг, aria, клавиатура, reduced-motion); privacy-индикатор на всех экранах с камерой; спокойный не-клинический тон CMF (никаких оценочных формулировок и alarm-цветов для внимания); `data-mode="kids"` должен каскадироваться без переделки компонента.
>
> **Композиция:** иерархия — типографикой и воздухом, не рамками. Один уровень поверхности на экран (канва + максимум один слой карточек, только для кликабельных объектов). Секции разделяй `--space-8/-10` и hairline. Главная метрика экрана — крупная табличная цифра + подпись, не виджет-коробка.
>
> **Цвет:** графитовая шкала для всего информационного; коралловый акцент — не больше одного смыслового употребления на состояние экрана и только «нужно действие», всегда в паре с текстом. Статусные цвета (success/error) — только для форм/системных состояний, никогда для метрик внимания.
>
> **Движение:** transitions только на токенных длительностях; ничего не переставлять при live-данных; появление — opacity/translate ≤ 8px; skeleton вместо спиннера.
>
> **Проверь перед сдачей** по чек-листу `.claude/skills/flamingo-design` (§Pre-merge) + добавь: нет новых поверхностей-коробок без функции; заголовочная иерархия не глубже трёх уровней; экран выдерживает +25% размера шрифта без поломки.
>
> Сначала покажи вайрфрейм-структуру текстом (зоны, иерархия), потом код. Если решение требует нового токена — предложи его отдельным диффом `tokens.css`, не инлайнь.

## 3. Что меняется в токенах (черновик tokens.css v2 — применять ПОСЛЕ утверждения)

Эволюция, не революция; тёплая палитра и весь семантический слой сохраняются (компоненты не трогаем).

- `--text-display: 3.25rem` (52) на ≥lg; добавить `--text-metric: 3.75rem` (60) — для крупных живых цифр дашбордов/CMF.
- Добавить `--space-13: 128px` для редакционных разрывов секций.
- `--radius-card: 16 → 14` **[на вкус владельца — проверить на превью]**; контролы без изменений.
- Тени: ослабить `--shadow-md/-lg` на ~20% (глубина — только у плавающего).
- Добавить `--stroke-hairline: 1px solid var(--color-border)` как именованный паттерн (санкционированный литерал в одном месте).
- Авто-тема: продублировать блок `[data-theme="dark"]` в `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }`.
- Иконки: `--icon-stroke: 1.75; --icon-size-sm/md/lg: 16/20/24px`.

Ничего из семантических ИМЁН не переименовывается — все существующие компоненты продолжают работать.

## 4. Порядок внедрения (после «да» от владельца по превью)

Каждый шаг — отдельный коммит, гейты зелёные, скрин-превью владельцу.
