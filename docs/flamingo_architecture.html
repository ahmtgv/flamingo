2. Бэкенд — путь запроса

flowchart TB
  REQ["HTTP / WebSocket"] --> ASGI["ASGI — uvicorn"]
  ASGI --> SCH["Strawberry schema — api/schema.py"]
  SCH --> RES["Resolvers — thin: auth, permission, input"]
  RES --> SVC["Services — business logic, transactions"]
  SVC --> ORM["Django ORM models"]
  ORM --> DB[("PostgreSQL")]
  RES -. permissions .-> PERM["common.permissions"]
  SVC --> TASKS["Celery tasks"]
  SVC --> CH["Channels group_send"]

Резолверы без бизнес-логики: авторизация и валидация → сервис (транзакции, сайд-эффекты) → ORM.
