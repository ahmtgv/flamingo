# R5 — СМЕТА НА БОЕВОЙ КОНТУР (подготовлено ревьюером, 13.08.2026)

**Для чего:** решение владельца по бюджету, после которого стартует фаза R5.
**Масштаб пилота:** 2 преподавателя английского · ~20 учеников · 15–25 занятий в неделю по 45–60 минут ·
до 8 участников в комнате одновременно.

⚠️ **Про точность цифр.** Прайс Yandex Cloud отдаётся динамически (страница цен — калькулятор, не статика),
поэтому ниже — **ориентиры из открытых источников на август 2026** и оценка по конфигурации.
Точные суммы берутся в [калькуляторе Yandex Cloud](https://yandex.cloud/ru/prices) перед оплатой.
С 1 мая 2026 действует повышение цен на часть сервисов — оно уже учтено в источниках.

---

## 1. Что обязано быть в РФ, а что нет

Наш собственный принцип (CLAUDE.md §2.3, 152-ФЗ): **персональные данные пользователей — на серверах в РФ.**
Из этого следует одно неочевидное, но важное:

- **LiveKit Cloud использовать нельзя.** Это удобно и дёшево ($50/мес тариф Ship со 150 000 минут участника,
  дальше $0.0005/мин — пилот покрылся бы с запасом), но медиапоток детей пошёл бы через зарубежную инфраструктуру.
  Мы весь продукт построили на обещании «ничего лишнего не покидает устройство» — ломать его ради $50 нельзя.
  **Значит LiveKit self-hosted**, в РФ. Лицензия у него Apache 2.0, платы за сам сервер нет.
- **Фронтенд остаётся на Cloudflare Pages** — там нет персональных данных, только статика. Бесплатно, уже работает.

## 2. Три варианта контура

### Вариант А — «пилот», минимально достаточный

| Компонент | Конфигурация | ₽/мес (оценка) |
|---|---|---|
| ВМ приложения: API (uvicorn) + Redis + Postgres | 4 vCPU (100%) / 8 ГБ RAM / 60 ГБ SSD | ~6 000 |
| ВМ медиа: LiveKit + coturn (TURN обязателен) | 2 vCPU (100%) / 4 ГБ RAM / 30 ГБ SSD | ~3 000 |
| Object Storage (материалы, доски, вложения) | ~50 ГБ | ~40 |
| Публичные IP (2 шт.) | | ~300 |
| Исходящий трафик | ~150–300 ГБ | ~1 500–3 000 |
| **Итого** | | **≈ 11 000–13 000 ₽/мес** |

Postgres и Redis живут на той же ВМ, что и приложение. Для пилота это нормально при условии
ежедневного бэкапа в Object Storage. Управляемых сервисов нет — значит и счёт вдвое меньше.

### Вариант Б — «надёжный», если пилот сразу боевой

| Отличие от А | ₽/мес (оценка) |
|---|---|
| Managed PostgreSQL вместо своего (SLA, PITR, бэкапы из коробки) | **от 5 500** |
| Managed Redis вместо своего | ~2 500–4 000 |
| **Итого** | **≈ 19 000–23 000 ₽/мес** |

Смысл переплаты один: не ты чинишь базу в субботу вечером, когда у преподавателя урок.
Point-in-Time Recovery для платформы, где хранятся работы и оценки детей, — не роскошь.

### Вариант В — с распознаванием речи для саммари

Речь в саммари требует своего распознавателя рядом с медиа (мы сознательно не стали делать это в браузере).

| Компонент | ₽/мес (оценка) |
|---|---|
| ВМ с GPU под whisper | **от 25 000–40 000** |
| ВМ CPU под whisper small (медленнее, батчами после урока) | ~4 000–6 000 |

**Моя рекомендация: на старте не брать вообще.** Саммари уже умеет собираться без речи —
в R4.2 мы разделили `lesson_summary` и `lesson_transcription` именно для этого. Пункты из речи просто
не появятся, всё остальное (доска, тест, чат, план) соберётся. Включим, когда станет ясно, что этого не хватает.

## 4. Рекомендация

**Начать с варианта А + бэкапы, без распознавания речи: ≈ 11–13 тыс ₽/мес.**

Обоснование: на двух преподавателях и двадцати учениках управляемые сервисы не окупаются, а GPU под речь —
это больше половины бюджета ради функции, которая на старте не обязательна. Переезд с варианта А на Б —
это перенос базы, а не переписывание продукта: код уже конфигурируется через переменные окружения,
никаких хардкодов адресов (требование R5 в промпте №13).

**Порог, после которого переходим на Б:** больше пяти преподавателей, либо первая же потеря данных,
либо появление платящих учреждений.

---

## 5. Что именно оплачивается в момент старта R5

1. Два инстанса + диски + IP — **сразу**.
2. Object Storage — по факту, копейки на старте.
3. Трафик — по факту; главный источник неопределённости, поэтому в смете он с запасом.

**Первый месяц имеет смысл считать экспериментом:** снимаем реальный трафик на живых уроках
и уточняем смету по факту, а не по прикидке.
