# WORKFLOW — Владелец · Ревьюер (Cowork) · Исполнитель (Claude Code)

**Установлено владельцем (Адель), 2026-07-03.** Обновлять при изменении процесса.

## Роли

- **Владелец** — ставит задачи, принимает решения, курьер промптов/отчётов, real-run с камерой/планшетом.
- **Ревьюер (Claude в Cowork, «архитектор»)** — превращает задачи владельца в промпты для Claude Code; держит планы/инварианты/дизайн-систему; проверяет сделанное ПО ФАЙЛАМ И GIT (у него прямой доступ к репо); дизайн-макеты; глубокие аудиты; НЕ пишет большие куски кода в приложение без крайней нужды (не может запускать гейты).
- **Исполнитель (Claude Code)** — реализует по промпту; ЗАПУСКАЕТ ГЕЙТЫ (это его машина); браузерная верификация (Playwright MCP); коммитит; пишет отчёт по формату.

## Цикл

1. Владелец → задача ревьюеру.
2. Ревьюер → **ПРОМПТ** (самодостаточный: контекст-файлы, задача, инварианты, приёмка, формат отчёта).
3. Владелец копирует промпт в Claude Code → забирает **ОТЧЁТ** → ревьюеру.
4. Ревьюер сверяет отчёт с реальным git/файлами, разбирает с владельцем, готовит следующий промпт.

## Формат ПРОМПТА (шапка обязательна)

```
Прочитай сначала: CLAUDE.md; docs/handoff/SESSION_HANDOFF.md §0;
docs/handoff/LIVEROOM_SEDUM_MASTERPLAN.md; docs/Flamingo_Redesign_Prompt_v2.md (язык Air).
Инварианты не обсуждаются: privacy CMF (эгресс = 8 агрегатных скаляров, только avgAttention в БД);
no <video> remounts (лейаут только data-атрибутами на стабильном .tiles); SDL только hand-add;
токены/i18n/AA; conventional commits по одному concern; гейты зелёные перед каждым коммитом.
ЗАДАЧА: <...>
ПРИЁМКА: <...>
ОТЧЁТ (обязателен, вернётся внешнему ревьюеру): см. ниже.
```

## Формат ОТЧЁТА исполнителя

1. Хэши коммитов + однострочники.
2. Вывод гейтов ЧИСЛАМИ (pytest N passed; vitest N passed; build/lint ok) — до и после.
3. Изменённые файлы и почему.
4. Скриншоты (пути в repo, `docs/handoff/shots/` — git-ignored крупные не коммитить, до 5 шт можно).
5. Отклонения от промпта/плана + вопросы.
6. Обновлены ли SESSION_HANDOFF §0 и чекбоксы мастер-плана.

Ревьюер ДОВЕРЯЕТ отчёту только после сверки с git diff.

## Разделение зон, чтобы не столкнуться

- Claude Code — единственный, кто пишет в `frontend/src`, `backend/` (код).
- Ревьюер пишет: `docs/**`, `FLAMINGO_HANDOVER.md`, `.claude/skills/*` (правила), дизайн-превью.
- Оба коммитят в одну ветку; перед началом сессии каждый делает `git log --oneline -5` и читает SESSION_HANDOFF §0.
