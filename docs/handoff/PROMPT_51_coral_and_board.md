## 2. 🔴 ДОСКА — ЧИНИТЬ ПО ЗАМЕРУ ВЛАДЕЛЬЦА, НЕ ЖДАТЬ СВОЕГО ПРИБОРА

Наряд 50 §2 остановился правильно: пробник не отличал «инструмент мёртв» от «пробник
смотрит не туда». Остановка засчитана (`§62.3`).

**Но замер владельца руками — это факт, и его достаточно, чтобы начать.** Дословно:

1. **ладошка не перетаскивает холст;**
2. **текст написать невозможно;**
3. **почти все функции не работают, кроме рисования** и вставки картинки, «и то она делает
   через раз»;
4. **доску сделать один в один как Freeform от Apple** (поведение, не оформление).

### Сначала — опоры для замера, потом починка

Причина, по которой пробник ослеп: он считал узлы по `svg g > *`, то есть угадывал строение
холста. **Не угадывать.** Первым делом проставить в `BoardCanvas` устойчивые метки:

- на каждый элемент холста — `data-el` с видом (`PEN` · `TEXT` · `STICKER` · `SHAPE` ·
  `LINK` · `IMAGE`) и `data-el-id`;
- на холст — `data-board-viewport` с текущим сдвигом и масштабом, читаемыми из DOM;
- на панель — `data-tool` на каждой кнопке.

После этого пробник считает не узлы, а **обещания**: «нажал Текст, щёлкнул — на холсте
появился `data-el="TEXT"` и в него можно печатать».

⚠️ Метки — не украшение и не для стилей. Только для замера.

### Затем — по одному инструменту

Порядок: **текст → ладошка → стикер → фигура → связь → картинка**. Текст первым, потому что
это второе, что преподаватель делает после пера.

По каждому: починить, и **доказать провалом** — сломать обратно, увидеть красное.

### Поведение — как во Freeform

Бесконечный холст · панорама ладошкой и пробелом · масштаб колесом и щипком · текст
щелчком сразу с курсором и правкой по двойному щелчку · объект выделяется, двигается,
меняет размер за углы, удаляется клавишей.

⚠️ **Оформление Apple не копировать.** Вид — с листа дизайнера, лист заказан
(`TASK_DESIGNER_2026-08-23b §1`). Пока листа нет — **чинить поведение, вид не менять**
(`§62.1`).

⚠️ **Порог штриха не понижать:** `MIN_STROKE_POINTS = 3`, `MIN_STROKE_LENGTH = 6`
(наряд 47 §5). Иначе случайное движение мышью снова начнёт пачкать урок навсегда.

🔴 **Синхронизацию доски не трогать.** Она проверена вторым человеком и работает
(`boardChanged` — единственная подписка, подтверждённая стандартным прогоном). Инструменты
чинятся **над** ней, а не вместо неё.
