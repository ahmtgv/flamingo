# D0 — SEduM диагностика: замеры и дефекты

**Дата:** 2026-07-06 · **Исполнитель:** Claude Code · **Статус: ЧАСТИЧНО — среда ИИ без камеры.**
Механика HUD и пайплайна проверена live с **синтетической камерой** (canvas.captureStream, лица нет).
Пять сценариев с реальным лицом — **OWNER REAL-RUN, PENDING** (таблица-заготовка ниже). Не считать D0
закрытым до прогона владельцем.

Проверка среды: student-вкладка `…/room?cmfDebug=1`, dev-сборка, HUD виден; egress перехвачен в
Network — `ReportAttention` = ровно 8 агрегатных скаляров (`sessionId, bucketStart, avgAttention,
gazeOnScreen, eyeOpenness, headYaw, headPitch, alertness`), кадров/landmarks в трафике нет.

## 1. Замерено (синтетика, no-face, 640×400 @15fps, 30+ сек)

| Метрика HUD | Значение | Вывод |
|---|---|---|
| status | `running` стабильно | воркер жив, MediaPipe инициализируется |
| rate | **5 / 5 Hz** стабильно | инференс держит целевую частоту; дропов нет |
| max gap | **208–216 ms** (цель 200) | межкадровый разбег ≤ +16 ms — пайплайн не лагает |
| jitter | **±0** | на константном входе скор не дребезжит (дребезг — от сигнала, не от пайплайна) |
| score | **0** постоянно | ⚠️ no-face кодируется НУЛЁМ, а не «нет данных» (дефект №1) |
| bucket | `att 0 · gaze 0 · eyes 0 · yaw 0 · pitch 0 · alert 0`, age ~2.2–2.3 s | кадентность бакетов ≈2.5 s подтверждена |

**Производительность пайплайна на синтетике проблем не показывает** → приоритет C1/Q2 над P3
(совпадает с решением владельца, masterplan §6.1).

**Подтверждённый live дефект №1 (0-vs-null):** при отсутствии лица воркер эмитит нули
(`extractSignals: facePresent=false → все 0`), сервер получает `avgAttention 0`, а фокус-бар учителя
показывает **«голова в кадре»** (`headState(0,0)='in'`) — т.е. «ученика нет» неотличимо от «ученик
смотрит с нулевым вниманием» и ложно рапортует голову в кадре. Компоненты: worker (нет
confidence-гейта FaceLandmarker), score/headState (0 — валидное значение). → вход Q2.

## 3. Гипотезы по дефектам (обоснованы кодом; проверить замерами §2)

| # | Ожидаемый симптом | Компонента | Механизм по коду | Фаза |
|---|---|---|---|---|
| 1 | «Нет ученика» = 0 и «голова в кадре» | worker + score | нет confidence-гейта; no-face → нули вместо null (подтверждено live, §1) | Q2 |
| 2 | Скор систематически «врёт» у конкретного человека | calibration (отсутствует) | скоринг абсолютный: `gazeOffScreenSpan 0.6`, EAR `0.15/0.3` фиксированы; личная посадка/веки/камера не учитываются; машина `calibration.ts` написана, но НЕ подключена к пайплайну | **C1** |
| 3 | «Пишу в тетради» → скор падает (владелец: НЕ должен) | gaze-блендшейпы + score | взгляд вниз даёт большие `eyeLookDown*` → `gazeOnScreen`↓ → primary-компонента роняет скор; head-pitch-вниз-стабильно не выделено как отдельное состояние | Q2 |
| 4 | Очки/прищур → «глаза закрыты», бодрость занижена | EAR | фиксированные пороги `earClosed 0.15 / earOpen 0.3` на landmark-EAR; очки искажают landmarks век; blink-fallback на блендшейпы тоже шумит в отражениях | C1+Q2 |
| 5 | Скор «скачет» между соседними бакетами без смены поведения | EMA + bucketing | `emaAlpha 0.4` на 5 Hz — свежий кадр весит 40%: морг/блик → провал; среднее по 2.5 s не спасает от ступенек; гистерезиса/асимметрии (быстро вверх, медленно вниз) нет | Q2 |
| 6 | Дребезг при повороте головы ~15° | head-euler + score | жёсткий обрыв: `abs(yaw)>15°` И gaze<0.5 → множитель 0.5 ступенькой; колебание вокруг порога → скачки | Q2 |
| 7 | Бодрость «залипает»/медленно отходит | alertness | окно blink-rate 30 s; при потере лица окно продолжает стареть; восстановление медленное | Q2 |
| 8 | Плохой свет → всё сразу занижено | FaceLandmarker вход | при низком качестве детекции blendshapes/landmarks шумят синхронно; без confidence-гейта шум идёт прямо в скор | Q2 |

**Сводка направления:** дефекты №2 (калибровка) и №1/№3/№5 (0-vs-null, тетрадь, стабилизация) —
структурные, тюнингом `cmfConfig` не лечатся → подтверждают порядок C1 → Q2 → T4 и решение
владельца о SEduM-NG (полное пере-R&D, masterplan §3).

## 4. Что было проверено в этом прогоне помимо HUD

- Композиция v3 (учитель): чип «имя · внимание» на тайле, коралловое кольцо + «нужно внимание» ниже
  порога, клик → фокус с полной разбивкой (взгляд/глаза/бодрость/голова + «Esc — свернуть»), Esc
  возвращает сетку, свой тайл ровно один (rail, «Так вас видят ученики»). Соосность: тайлы сетки и
  rail оба AR 1.600 (16:10), верхние кромки выровнены (Δ≤1px) — CSS-правок не потребовалось.
- Ученик: своих метрик НЕ видит (Strip снят, v3) — на экране только privacy-строки и HUD (dev).
- Скриншоты: `docs/handoff/shots/` (см. отчёт).
