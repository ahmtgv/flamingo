# Аудит по ролям · 17.08.2026 (промпт 27 §1)

Проход по живому стеку: вход настоящей учёткой, запросы к работающему серверу, экраны в
браузере. Учётки заведены самим (`trial.*@flamingo.test`).

Четыре вопроса на роль: **может ли · где застревает · чего нет совсем · что при отказе.**

---

## Ученик

| вопрос | ответ |
|---|---|
| **Может ли учиться и видеть своё?** | **Да.** Вход → стартовая (лист 00) → предмет → комната урока. Внимание пишется: 118 корзин за пробное занятие. Сохранённое кладётся в свою папку и уезжает в зеркало. |
| **Где застревает** | 1. **Баллы** нигде: были в старом кабинете, на стартовой их нет. 2. **Повторение** доступно только строкой в «Требует внимания» — своей двери у `/repetition` нет ни на одном экране. 3. **Аватар** менять негде: раздел листа D8 не начат. |
| **Чего нет совсем** | Произношение слов (`pronunciationId` есть, звука нет ни на сервере, ни в выдаче — кнопка выключена честно). «Напомнить» из меню уголка: механизма напоминаний в продукте нет. |
| **Что при отказе** | Сети нет / сервер отказал — **теперь разные слова** (было одно на оба). Данных ещё нет — «Загрузка…», через 4 с объяснение и кнопка. Данных нет вовсе — пустое состояние своими словами в каждом слоте. |

## Преподаватель

| вопрос | ответ |
|---|---|
| **Может ли провести урок?** | **Да, и это главное изменение суток.** «Начать урок» из приглашения открывает комнату (было — расписание). Рама показывает урок: название в заголовке, «Связь / Подключено / Идёт», переключатели окон в полосе, «Завершить». |
| **Где застревает** | 1. **«Подключено 0 из 0»** при живом уроке — список посещаемости пуст, разбираться не начинал. 2. **Материалы** к занятию прикрепить можно только через урок курса; со стартовой строка «Материалы не прикреплены» ведёт в задания урока, а не в материалы. 3. **Верификация**: баннер теперь на стартовой, но пока документ не одобрен, ограничений на ведение нет — то есть баннер сообщает, а не решает. |
| **Чего нет совсем** | «Скопировать ссылку» в раме (нужен ключ группы в комнате). Методичка — вкладка есть, содержимого нет; текст больше не винит данные. |
| **Что при отказе** | Как у ученика. Плюс отказ по состоянию учётки: «Учётная запись ограничена: вести занятия нельзя» — отдельными словами, не «что-то пошло не так». |

## Родитель

| вопрос | ответ |
|---|---|
| **Может ли знать, как идут дела?** | **Частично.** `me.parentProfile.children` отвечает — дети видны. Экран для этого один: прежний кабинет `/app`. |
| **Где застревает** | Стартовая для него пуста по построению (`startPage.profile = null` — учебного профиля у родителя нет), и `/start` осознанно уводит его на `/app`. То есть новая половина продукта его не касается вовсе. |
| **Чего нет совсем** | Лист родителя не рисовался и не будет (решение владельца §27.3). Всё, что у него есть, — старый кабинет: дети, добавить ребёнка, согласие 152-ФЗ. |
| **Что при отказе** | Старый кабинет, старые состояния: `ErrorState` теперь тоже различает связь и отказ. |

## Админ учреждения

| вопрос | ответ |
|---|---|
| **Может ли вести учреждение?** | **Нет — застревает на нулевом шаге.** `me.adminProfile.institution = null`, и экран честно пишет: «Вы пока не привязаны к учреждению. Его создаёт платформа и назначает администратора». |
| **Где застревает** | Там же. **`createInstitution` в схеме есть и не вызывается ни одним экраном** — это одна из 44 осиротевших операций. Платформе создать учреждение тоже негде: в панели надзора такого раздела нет. |
| **Чего нет совсем** | Дверь к созданию учреждения. Не строил намеренно: §9 запрещает начинать надзор D7 сверх «Людей». |
| **Что при отказе** | Надзор отвечает «Надзор доступен только сотруднику платформы» — отдельными словами, а не общим отказом. Проверено всеми четырьмя ролями. |

## Карта действий (§1.3) — числом

Механическая проверка `silentControls.test.ts`: каждая кнопка обязана иметь обработчик либо
быть выключенной с подписью.

| | сколько |
|---|---|
| кнопок проверено | **все `<button>` и `<Button>` в `src`, кроме витрины** |
| «нарисовано и молчит» найдено | **1** — «▶» произношения в словаре |
| осталось после починки | **0** |
| выключенных с честной подписью | 37 (разрешённое состояние) |

⚠️ Чего сторож не умеет: он читает разметку, а не граф вызовов. `onClick={props.onOpen}` для
него «обработчик есть», даже если проп не передали — ровно дефект «Открыть кабинет» 15.08.
Ловит самый грубый случай из четырёх, и это сказано в самом тесте.

Отдельно: **сам сторож дважды соврал в сторону «всё плохо»** — резал тег по `>` внутри
`icon={<Video />}` (11 ложных) и читал `<button>` из JSDoc как разметку (1 ложный). Обе
ошибки закрыты самопроверкой внутри теста; без неё я бы «чинил» одиннадцать исправных кнопок.
