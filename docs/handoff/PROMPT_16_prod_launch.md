## 3. БЛОК А · ПРОД-КОНТУР

### А1. CORS и CSRF — без этого ничего не заработает
`BACKEND_DEPLOY_PLAN.md §43`: `django-cors-headers` не подключён. Подключить.
`CORS_ALLOWED_ORIGINS` и `CSRF_TRUSTED_ORIGINS` читаются **из окружения**, значения не хардкодить.
Фронт на `flamingo.plus`, API на `api.flamingo.plus` — это разные origin, браузер зарежет всё.

**Приёмка:** запрос с `Origin: https://flamingo.plus` получает нужные заголовки; запрос
с постороннего origin — не получает.

### А2. `_redirects` — корневая причина R-01
`frontend/public/_redirects` содержит `/* → /index.html 200`, и это правило перехватывает
`/graphql/`: Cloudflare отдаёт HTML, `HttpLink` парсит его как JSON и валится. Ошибка при этом
**мимикрирует под ответ сервера** — самый дорогой вид поломки.

Добавить исключение для `/graphql*` (и для `/api*`, если появится). Проверить, что после сборки
файл попадает в `dist`.

### А3. Прод-настройки Django
- `DEBUG` из окружения, по умолчанию **выключен**;
- `ALLOWED_HOSTS` из окружения;
- `SECURE_PROXY_SSL_HEADER` — приложение стоит за Caddy, без этого Django считает соединение
  небезопасным и ломает cookie и редиректы;
- статика админки, если она вообще нужна в проде;
- логи в stdout (их собирает docker), без файлов.

### А4. Миграции на чистой базе
Поднять postgres из compose, прогнать `migrate` в контейнере **с нуля**. Сообщить число миграций
и время. Любой ручной шаг посреди — дефект, чинить.

### А5. coturn — проверка, не переписывание
`backend/common/turn.py` уже отдаёт кредентивы. Проверить, что:
- `TURN_URLS`, `TURN_SECRET`, `TURN_TTL_SECONDS` читаются из окружения в проде;
- секрет, которым подписывается кредентив, тот же, что в `--static-auth-secret` контейнера;
- `--external-ip` совпадает с публичным адресом (иначе ICE-кандидаты укажут в никуда);
- секрет **не уходит клиенту** — тест уже есть, убедиться, что он покрывает прод-путь.

### А6. Сборка проверяется целиком
`docker compose -f infra/prod/docker-compose.prod.yml config` проходит; образ api собирается;
контейнер стартует; `/graphql/` отвечает. Если `backend/Dockerfile` dev-only — довести до прода
(без dev-зависимостей, без `--reload`).

### Б5. Ступени токенов — не заводить
Значения из листов (радиусы 2/3/5/7px, отступы в px) округлять к ближайшей существующей ступени.
**Правило: лист — рисунок, код — токены.** Расхождение в один-два пикселя между листом
и реализацией дефектом не считается и в реестр не пишется.
