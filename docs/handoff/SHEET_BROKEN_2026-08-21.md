# Лист «Создание курса и занятия» не открывается — одна лишняя скобка

**Дата:** 21.08.2026. **Коммит листа:** `eaf6ae6`. **Кому:** дизайнеру.

## Что происходит

Лист не выполняется вовсе. В переключателе видов вместо кнопок стоит красная плашка:

```
Создание курса и занятия: Unexpected token '}'
```

Виды **«перенос и отмена»** и **«правка курса»** — те два, ради которых выгрузка и делалась —
не рисуются: кадр пустой. Первые два вида («курс», «занятие») тоже не работают, просто их
успели посмотреть до этой выгрузки.

## Где именно

`docs/design-handover/Создание курса и занятия.dc.html`, **строка 698**:

```js
: { title: empty ? 'Новое занятие' : 'Занятие 12 · Почему горит магний',
    sub: 'курс «Химия · неорганика» · время задаётся в вашем поясе: Москва, UTC+3' }));
                                                                                   ^ лишняя
```

Тернарник `course ? {…} : (move ? {…} : {…})` закрывается одной скобкой, а стоит две.

**Правка — один символ:** `}));` → `});`

Проверено: вынул скрипт листа, `node --check` показывает ровно это место; с убранной скобкой
разбирается без ошибок.

## Что это значит для работы

Собрать «перенос и отмену» с листа нельзя — я его не видел. Экран отложен до исправленной
выгрузки; в очереди наряда 45 иду дальше, к мастеру первого запуска.

Собирать по описанию из наряда (причина обязательна, ветка переноса назад, два действия и
честная строка) не стал намеренно: это была бы догадка о виде, а лист существует именно
затем, чтобы не гадать.

## Заодно: чем это ловится в другой раз

Ошибка синтаксиса в листе видна только при открытии его глазами. Прогон приборов её не
поймает — приборы меряют СОБРАННЫЙ продукт, а не листы. Дешёвая проверка на вашей стороне:

```bash
node --check <(sed -n 's/.*<script[^>]*>//p' лист.dc.html)   # грубо, но ловит
```
