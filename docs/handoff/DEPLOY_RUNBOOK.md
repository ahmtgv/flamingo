# РАЗВЁРТЫВАНИЕ ТОЧКИ ВСТРЕЧИ — ПОШАГОВО

**Кому:** владельцу (Адель). **Цель:** поднять сервер, без которого не работают регистрация,
связывание машины, приглашение ученика и «преподаватель в сети» — то есть всё, что нужно
для первого урока.

**Стоимость после запуска:** ~500–900 ₽/мес за VPS. TURN — 0 ₽ (Cloudflare даёт 1000 ГБ
в месяц бесплатно, наш худший случай — 148 ГБ). Раздача сайта — 0 ₽ (Cloudflare Pages).

---

## Кто что делает

**Ревьюер (я)** — всё, что не требует твоих паролей: конфигурация сервера, TLS, состав
контейнеров, переменные, инструкции. Уже готово: `infra/prod/`.

**Исполнитель (Claude Code)** — код: перевод выдачи TURN-кредентивов на Cloudflare,
`Dockerfile` под прод, проверка миграций на чистой базе. Задание — в конце файла.

**Ты** — только то, что требует входа под твоей учётной записью и денег. Я не завожу аккаунты
и не ввожу пароли: это твои ключи, и они должны оставаться твоими.

## ШАГ 1 · Арендовать VPS в России ⏱ 10 минут

**Что взять:** 2 ядра · 2 ГБ памяти · 20–40 ГБ диска · Ubuntu 24.04. Публичный IP.
Дата-центр — **обязательно в РФ** (152-ФЗ: персональные данные детей).

Подойдёт любой российский провайдер. Ориентир по цене — 400–800 ₽/мес за такую машину.
У многих есть стартовый грант новым аккаунтам: на пилот из двух преподавателей его хватит
на несколько месяцев.

**Что записать и прислать мне:** IP-адрес сервера. Пароль root — **не присылай**,
он мне не нужен ни при каком раскладе.

---

## ШАГ 2 · Направить домен на сервер ⏱ 5 минут

В Cloudflare, где живёт `flamingo.plus`, добавить А-запись:

| Тип | Имя | Значение | Проксирование |
|---|---|---|---|
| A | `api` | IP из шага 1 | **выключено** (серое облако) |

⚠️ **Облако должно быть серым.** С оранжевым Caddy не выпустит сертификат, а WebSocket
для подписок пойдёт лишним кругом. Это единственное место, где ошибка стоит часа разбирательств.

Проверить через пару минут: `ping api.flamingo.plus` должен отвечать твоим IP.

---

## ШАГ 3 · Получить ключ TURN у Cloudflare ⏱ 5 минут

Cloudflare → **Realtime** → **TURN** → создать приложение (назвать `flamingo`).

Скопировать **два значения**: `Key ID` и `API Token`. Токен показывается один раз —
сохрани в менеджере паролей.

Это и есть бесплатная ретрансляция: 1000 ГБ в месяц. Свой сервер для этого не нужен.

---

## ШАГ 4 · Заполнить файл секретов ⏱ 10 минут

На сервере, в папке проекта, скопировать пример и заполнить:

```bash
cp infra/prod/.env.production.example .env.production
nano .env.production
```

Заполнить пять полей:

| Поле | Откуда взять |
|---|---|
| `SECRET_KEY` | `python3 -c "import secrets; print(secrets.token_urlsafe(64))"` |
| `POSTGRES_PASSWORD` | `openssl rand -base64 32` |
| `CLOUDFLARE_TURN_KEY_ID` | шаг 3 |
| `CLOUDFLARE_TURN_API_TOKEN` | шаг 3 |
| `API_DOMAIN` | уже стоит `api.flamingo.plus` — проверить |

Файл в git не попадает — он в `.gitignore`. Никому его не пересылай, включая меня.

## ШАГ 5 · Запустить ⏱ 15 минут

На сервере:

```bash
# один раз: docker
curl -fsSL https://get.docker.com | sh

git clone <адрес репозитория> flamingo && cd flamingo
# сюда положить .env.production из шага 4

docker compose -f infra/prod/docker-compose.prod.yml --env-file .env.production up -d
docker compose -f infra/prod/docker-compose.prod.yml logs -f api
```

Сертификат выпустится сам в первые секунды. Признак успеха: `https://api.flamingo.plus/graphql/`
открывается и отвечает (не белый экран браузера, а ответ API).

---

## ШАГ 6 · Подключить сайт к серверу ⏱ 5 минут

Cloudflare Pages → проект `flamingo` → **Settings → Environment variables**:

| Переменная | Значение |
|---|---|
| `VITE_GRAPHQL_HTTP_URL` | `https://api.flamingo.plus/graphql/` |
| `VITE_GRAPHQL_WS_URL` | `wss://api.flamingo.plus/graphql/` |
| `VITE_PUBLIC_ORIGIN` | `https://flamingo.plus` |
| `VITE_PREVIEW` | **удалить, если есть** |

Пересобрать деплой кнопкой **Retry deployment**.

С этого момента сайт перестаёт быть витриной: регистрация начинает работать по-настоящему.

## ШАГ 7 · Проверка ⏱ 10 минут

По порядку, каждый пункт — либо да, либо стоп и разбор:

1. `https://flamingo.plus` открывается, знак бренда на месте.
2. Регистрация преподавателя проходит и **не** показывает красную плашку.
3. Вход под этой учёткой работает, попадаешь на стартовую страницу.
4. Приложение на маке: код связывания принимается, мастер доходит до конца.
5. Замер канала показывает число и вердикт размером группы.
6. Ссылка приглашения открывается во втором браузере и показывает экран ожидания.

Дальше — живая приёмка по `LIVE_ACCEPTANCE.md`, там восемь шагов и числа вместо «работает».

## Что делать, если что-то пошло не так

| Симптом | Причина в девяти случаях из десяти |
|---|---|
| Сертификат не выпускается | оранжевое облако в Cloudflare (шаг 2) |
| Сайт висит на «Загрузка…» | не пересобран деплой после шага 6 |
| Регистрация даёт ошибку | `CORS_ALLOWED_ORIGINS` не совпадает с адресом сайта |
| Ученик не подключается | ключ TURN не заполнен (шаг 4) |
| Всё поднялось, но пусто | база пустая — так и должно быть, демо-данных в проде нет |

## ЗАДАНИЕ ИСПОЛНИТЕЛЮ (не владельцу)

1. **TURN через Cloudflare.** `backend/common/turn.py` сейчас выдаёт кредентивы coturn
   (HMAC поверх статического секрета). Добавить провайдера `cloudflare`: запрос к их API
   за короткоживущими кредентивами, выбор по `TURN_PROVIDER`. coturn остаётся запасным путём,
   ничего не удалять. Тесты: провайдер выбирается конфигурацией; секрет не уходит клиенту.
2. **`backend/Dockerfile` под прод** — если его нет или он dev-only.
3. **Прогон миграций на чистой базе** в контейнере: 51 миграция должна пройти без ручных шагов.
4. **Проверить `CORS_ALLOWED_ORIGINS` и `CSRF_TRUSTED_ORIGINS`** — читаются ли из переменных
   (в `BACKEND_DEPLOY_PLAN.md` §43 отмечено, что `django-cors-headers` не подключён).
5. Не трогать `.env.production` и не коммитить секреты.
