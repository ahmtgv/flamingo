# Flamingo — Redesign Prompt v2 «FLAMINGO AIR» (заменяет v1)

**Дата:** 2026-07-03 · **Статус:** активное R&D-направление по решению владельца (Адель)
**Референс:** терминальная эстетика Grok Build (холодный светло-серый, моноширинный шрифт как стиль, тонкие рамки, пустота) × Apple-класс минимализма.
**Решение владельца:** v1 «тёплый редакционный минимализм» отклонён; тёплая палитра брифа §8 сознательно заменяется холодным нейтралом. Продуктовый принцип «долгое чтение без усталости» сохраняется другими средствами: спокойный контраст (чернила #1d1d1f, не #000), большие межстрочные, крупный кегль тела.

## 1. Язык «Flamingo Air»

### Палитра (холодный нейтрал + один коралл)

| Роль | Light | Dark |
|---|---|---|
| Канва | `#f1f1ef` | `#101012` |
| Поверхность | `#ffffff` | `#1a1a1c` |
| Поверхность-subtle | `#e9e9e6` | `#242426` |
| Чернила | `#1d1d1f` | `#f2f2f0` |
| Вторичный | `#6e6e73` | `#98989e` |
| Третичный (декор) | `#98989e` | `#6e6e73` |
| Hairline | `#d9d9d6` | `#2e2e31` |
| Акцент (графика/CTA) | `#e14e1f` (coral) | `#ff7040` |
| Акцент-текст | `#c23f14` | `#ff8a5f` |

Правила цвета: всё информационное — нейтральная шкала; коралл — ровно одно смысловое употребление на состояние экрана (primary-действие ИЛИ «нужно внимание»), всегда в паре с текстом; статусные цвета только в формах/системных ошибках, никогда в метриках внимания.

### Типографика — два голоса

- **UI/заголовки:** SF-стек `-apple-system, 'SF Pro Display', Inter, system-ui` (веб-fallback Inter). Display 56–64, weight 600, tracking −0.02…−0.03em. Тело 16–17/1.6, weight 400.
- **«Машинный» голос — моно:** `'JetBrains Mono','SF Mono','IBM Plex Mono'` для: живых цифр, времени, kicker-меток разделов, статусов, счётчиков, meta-строк. Tabular figures + зарезервированная ширина у всего живого. Кириллица — sentence case, без uppercase-трекинга.

### Композиция

- Пустота — материал: один смысловой центр на экран; секции разделяются ≥ 64px и hairline.
- Поверхность-карточка ТОЛЬКО у кликабельного/отделимого объекта; остальное — на канве.
- Контролы: 1px hairline-рамка, radius 10–12px, заливка только у единственного primary.
- «Стекло» санкционировано ровно в двух местах: sticky-навигация (`blur(20px)`, полупрозрачная канва) и frosted-оверлеи поверх живого видео (AttentionStrip).
- Глубина: тени почти исчезают — hover карточки = hairline→strong + подъём 2px + едва заметная тень; модалки/меню — единственные «плавающие».

### Движение

120–320ms, `--ease-standard`; только opacity / translate ≤ 8px / width; стабильные позиции при live-обновлениях; skeleton вместо спиннеров; reduced-motion → 0ms.

### Неизменные инварианты (не обсуждаются в рамках стиля)

Только семантические токены (никаких hex/px в компонентах, кроме санкционированных 1px/2px/blur); ru-i18n; WCAG 2.1 AA (фокус-ринг виден, aria, клавиатура, +25% шрифта без поломки); privacy-индикатор на всех камерных экранах; спокойный не-клинический CMF-тон; `data-mode="kids"` каскадом токенов; грамматика Meter / орбов / стабильных позиций сохраняется — меняется кожа, не смысл.

## 2. Рабочий промпт для каждого экрана

> Ты перерисовываешь экран `<ИМЯ>` нашего проекта Flamingo в языке «Flamingo Air» (§1). Сначала дай текстовый вайрфрейм: зоны → иерархия → где ЕДИНСТВЕННЫЙ акцент. Затем код: только семантические токены; моно — для всего машинного; поверхности — только у кликабельного; hairline вместо теней; движение по токенам. Новые токены предлагай отдельным диффом tokens.css. Перед сдачей проверь: чек-лист `.claude/skills/flamingo-design` + «не больше одного акцента», «ни одной коробки без функции», «+25% шрифта не ломает», «kids-режим каскадится».
