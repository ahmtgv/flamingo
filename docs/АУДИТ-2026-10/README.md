# Генеральный аудит Flamingo — октябрь 2026

Распоряжения владельца (19–25.10.2026) на глубокий аудит всего проекта: код,
вёрстка, дизайн, UX, бэкенд, будущие страницы, мусор. Выполняют **параллельные
сессии Claude Code** — по одной на область. Аудит **пишет отчёт**, а чинит сам
только **бесспорное** (см. `00-ОБЩЕЕ.md`, раздел «Что чинить самому»).

## Как запустить

Каждая сессия открывается в корне репозитория `Flamingo` на маке. Первое
сообщение сессии — одна строка, остальное она прочитает сама:

| № | Область | Первое сообщение сессии |
|---|---|---|
| 01 | Код фронта | `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/01-КОД-ФРОНТ.md, и выполни распоряжение целиком.` |
| 02 | Код бэкенда | `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/02-КОД-БЭК.md, и выполни распоряжение целиком.` |
| 03 | Вёрстка и дизайн | `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/03-ВЁРСТКА-И-ДИЗАЙН.md, и выполни распоряжение целиком.` |
| 04 | UX и пути | `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/04-UX-ПУТИ.md, и выполни распоряжение целиком.` |
| 05 | Будущие страницы | `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/05-БУДУЩИЕ-СТРАНИЦЫ.md, и выполни распоряжение целиком.` |
| 06 | Мусор | `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/06-МУСОР.md, и выполни распоряжение целиком.` |
| 07 | Проверка и сводка | **после 01–06:** `Прочитай docs/АУДИТ-2026-10/00-ОБЩЕЕ.md, затем docs/АУДИТ-2026-10/07-СВОДКА.md, и выполни распоряжение целиком.` |

Сессии 01–06 независимы и идут одновременно. Сессия 07 — одна, после всех.

## Куда ложатся результаты

- отчёты — `docs/АУДИТ-2026-10/отчёты/0N-<область>.md`, по одному на сессию;
- правки бесспорного — коммиты в ветке `аудит/0N-<область>`, по одной находке
  на коммит, ни одного коммита в `main`;
- сводный отчёт — `docs/АУДИТ-2026-10/ОТЧЁТ.md` (пишет сессия 07);
- решения владельца по находкам — `docs/РЕШЕНИЯ-ВЛАДЕЛЬЦА-<дата>.md`, как всегда.
