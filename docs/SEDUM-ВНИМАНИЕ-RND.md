# SEduM · внимание — исследование (R&D), 06.10.2026

Полная версия с цифрами, графиком и источниками — страница «R&D внимания SEduM»
(claude.ai, приватная у владельца). Здесь — выжимка для репозитория.

**Статус: движок не изменён.** Все правки ниже ждут решения владельца
(правило «обсуждаем и внедряем», CLAUDE.md §3а). На экран ничего нового не
выносим — решение 06.10.

## Главное

1. **Правила поверх видимого — верный путь.** Лицо, поворот головы, глаза, окно —
   самая надёжная часть науки. Обученные модели вовлечённости: 65–71% при 49%
   у «всегда высокая» (DAiSEE, EngageNet), на чужих данных проседают всегда.
   Обучать будем позже и на своих данных.
2. **Камера видит поведение, не мысли.** «Витает в облаках» ловится с AUC
   ≈ 0,6–0,65 на новых людях. Балл = «видимая вовлечённость».
3. **Терпение 3 с мало.** «Думающий» отвод взгляда — 3,54 ± 1,26 с (Andrist 2013).
   Ложно засчитаем: 3 с — 67%, 4 с — 36%, **5 с — 12%**, 6 с — 2,5% (наш расчёт).
4. **Ошибка в движке.** При опущенной голове веки выглядят закрытыми, и таймер
   `закрытыС` в `Внимание.шаг` тикает, хотя ученик пишет.
5. **Сон — доля закрытых глаз за минуту (PERCLOS).** r = 0,875 с провалами
   внимания (Dinges 1998). 5–10 к/с хватает. Частота морганий — нет.
6. **Взгляд — только крупные зоны.** Лево/центр/право; верх/низ после калибровки;
   дети — смещение ≈ 38% экрана (Kandel & Snedeker 2024), им только лево/право.
7. **«Пишем» по речи учителя — в его браузере.** Silero VAD → Vosk small
   streaming ru (≈ 28 МБ, WER 11,3) → rubert-tiny2 + kNN по образцам → сплав с
   долей опущенных голов. Не список фраз.
8. **Класс только оправдывает.** Синхронность взгляда предсказывает тест в лабе
   и дома (Madsen 2021, r = 0,47), но на веб-камерах ~7 к/с не повторилась
   (Sauter 2022).

Следующим шагом (когда комната сообщает, что открыто у ученика): зоны,
совпадение с курсором учителя (Pursuits, r ≥ 0,8, окна 1,5–3 с), «класс
сделал то же» (≥ 60–70% за ~10 с — штраф снимается), «пишем» по речи,
телефон только если виден в кадре (детектор 1–2 раза в секунду).

## Сознательно не берём

- Обучение на DAiSEE / EngageNet (взрослые 18–37, шумные метки: эксперты
  совпадали точно в 46%).
- Эмоции (скука, растерянность).
- Частоту морганий — ни для сна, ни для внимания (мета-анализ 2025).
- WebGazer (GPL, поддержка закончилась 24.02.2026, дрейф +49% за 20 мин).
- Точку взгляда в пикселях; сетку 3×3 для детей.
- Whisper и облачное распознавание; список фраз.
- «Телефон» по позе головы; синхронность как повод снизить балл.

## Пилот (10 взрослых из команды, 2 недели)

- **Неделя 1, по сценарию:** 2 сессии по ~25 мин (обычный и вечерний свет,
  очки/без). 11 сценок по 60 с в случайном порядке, дважды. Окна 5 с,
  точность и полнота по каждому состоянию. Пороги — «подобрали на 9,
  проверили на 10-м», по кругу; затем заморозка.
- **Неделя 2, живые уроки:** 3–4 урока по 45 мин; вопрос «Где было внимание?»
  раз в 4–7 мин; меряем, предсказывает ли балл за 30 с до вопроса ответ.
- **Речь:** 200–500 фраз учителей → WER Vosk vs GigaAM, точность «пишем».
- Записываем только числа, не видео (решение владельца).
