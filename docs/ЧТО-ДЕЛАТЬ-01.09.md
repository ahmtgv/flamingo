## ⚠️ Шаг 11. Важное: учётные записи не переезжают

Пока сайт работал без этой переменной, регистрации ложились в **D1 на Cloudflare**.
У вашего сервера **своя** база, и переноса между ними никто не писал.

Это значит: после шага 10 **надо зарегистрироваться заново** — той же почтой,
любым паролем. Старые записи останутся в D1 и просто перестанут использоваться.

Так и было задумано (в D1 сейчас только ваши пробные записи), но узнать об этом
лучше здесь, а не на экране входа.

## Шаг 12. Сделать себя преподавателем

Сейчас вы записаны учеником — видно по кабинету: он говорит «Мой учебный кабинет».
Роль меняется на сервере, после регистрации из шага 11:

Сначала посмотреть, кто есть:

```
cd /opt/flamingo/backend
.venv/bin/python manage.py shell -c "
from people.models import Person
for p in Person.objects.all(): print(p.id, p.email, p.name, p.role)
"
```

Потом поменять роль себе:

```
.venv/bin/python manage.py shell -c "
from people.models import Person
p = Person.objects.get(email='ваша@почта')
p.role = 'teacher'; p.save(); print('теперь', p.role)
"
```

Обновить страницу — в шапке должно стать «Кабинет преподавателя», а справа
появиться «Создать урок» и «Журнал».

## Шаг 14. Беречь теперь ДВА места

Раньше терялась только база. Теперь их два, и теряются они порознь:

| Что | Где |
|---|---|
| Люди, занятия, журнал | `/var/lib/flamingo/flamingo.sqlite3` |
| Пособия | `/var/lib/flamingo/materials/` |

База без папки даст журнал, где у каждого урока «файл не найден на диске».
Папка без базы — гору файлов без имён и хозяев. **Снимать копии вместе:**

```
crontab -e
```

```
17 4 * * * sqlite3 /var/lib/flamingo/flamingo.sqlite3 ".backup '/var/backups/flamingo-$(date +\%F).sqlite3'" && tar czf /var/backups/materials-$(date +\%F).tgz -C /var/lib/flamingo materials
```

## Если что-то пошло не так

| Что видите | Что это | Что делать |
|---|---|---|
| `git pull` ругается на локальные изменения | на сервере кто-то правил файлы руками | `git stash` и повторить `git pull` |
| `migrate` пишет `no such table: people` | база не там, куда смотрит `DB_PATH` | сверить `DB_PATH` в `.env` |
| `прогон.py` падает на импорте | не поставились зависимости | повторить шаг 3, строку с `pip install` |
| `systemctl status flamingo` красный | смотреть `journalctl -u flamingo -n 50` | чаще всего опечатка в `.env` |
| Загрузка файла отваливается на 413 | шаг 7 не сделан или nginx не перезагружен | `nginx -t && systemctl reload nginx` |
| Файл не доезжает, ошибка 413 | режет nginx | шаг 7, потом `systemctl reload nginx` |
| Журнал говорит «сервер не отвечает» | переменной `VITE_AUTH_URL` нет или выкат не повторён | шаг 10 |
| В кабинете «Мой учебный кабинет» | вы записаны учеником | шаг 12 |
