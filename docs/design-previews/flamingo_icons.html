flamingo  иконки

Линейные иконки, единая толщина, скруглённые концы — спокойно и тепло, без визуального шума. Возрастная адаптация — размером и мягкими подложками, не сменой библиотеки.

Размеры и толщина штриха

16 / 1.5pxв строке
20 / 1.75pxкнопки
24 / 2pxбаза, навигация
32 / 2pxакцент, пустые экраны
48 / 1.75pxонбординг, детский

Чем мельче иконка, тем тоньше штрих — оптическая плотность остаётся ровной. Тап-цель всегда ≥44px (≥48px в детском), даже если сама иконка меньше.

Цветовые состояния

обычная (ink) активная (coral-700) на кнопке (white) успех ошибка warning

По умолчанию иконка цвета текста. Коралл — только активное/интерактивное. Семантические цвета — только для семантических иконок.

Детский режим против взрослого

взрослый: 20px, нейтральная подложка
детский: 32px, мягкая коралловая подложка

Тот же набор Lucide — для младших просто крупнее и в тёплой скруглённой подложке. Не меняем библиотеку и не переходим на залитые «мультяшные» иконки.
