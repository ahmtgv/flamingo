## Что такое лист атласа

Один самодостаточный HTML-файл на раздел, на токенах «Flamingo Air»
(`docs/Flamingo_Redesign_Prompt_v2.md`), с переключателями:
- **все состояния данных**: пусто · загрузка (skeleton) · ошибка · заполнено · переполнено (много данных);
- **темы**: светлая · тёмная; **режимы**: обычный · kids (1–4 класс);
- все интерактивные состояния ключевых элементов (hover рисуется статикой рядом, фокус-ринги видимы).

## Цикл работы (см. docs/handoff/WORKFLOW.md)

1. Ревьюер рисует лист → владелец открывает в браузере, кликает, даёт правки → итерации до «идеально».
2. Утверждённый лист получает пометку ✅ в таблице ниже (+дата) — с этого момента он контракт.
3. Только после ✅ — промпт Claude Code на реализацию; приёмка = скрин-сверка с листом
   (Playwright у исполнителя, Chrome MCP у ревьюера) + чек-лист `.claude/skills/flamingo-design` + a11y-audit.

## ГДЕ ЖИВЁТ ДИЗАЙН (правило, действует с 13.08.2026)

**Единственное место — эта папка `docs/design-previews/atlas/`.** Один экран = один самодостаточный HTML-лист.
Правки вносятся **в лист**, а не в код: код догоняет лист, никогда наоборот.

- `_archive/` — прежний интерфейс. **Не контракт**, ссылаться при реализации нельзя.
- Дизайн-система (`tokens.css`, палитра, типографика, иконки) не меняется — она пережила пересборку.
- Один лист правится в одном коммите с явным pathspec; в блоке «что здесь решено» пишется **почему**,
  чтобы решение нельзя было отменить по невнимательности.

### Две серии листов

| Серия | Что описывает | Статус |
|---|---|---|
| **Веб (00–12)** | То, что уже реализовано и работает в браузере | контракт |

## Глобальные дизайн-решения владельца (действуют на все листы)

- **Метрики внимания ученику:** live — никогда (только учителю, v3); агрегированная сводка — только в личном кабинете (лист 10). На дашборде ученика — прогресс по курсам.
- **Свёртка списков дня:** с 10 элементов — «Ещё N …».
- **Онбординг-тур:** не в MVP; пустые состояния несут одну ясную CTA.
- **Аналитика внимания преподавателю:** сразу после занятия (отчёт) + из настроек/аналитики; НЕ на дашборде.
- **Цены:** пока всё бесплатно — цену/«бесплатно» не упоминаем нигде; место под цену заложено в aside курса.
- **Расписание:** дефолт список; переключатель список/неделя/месяц; отменённые видимы + «скрыть отменённые».

## Правила листов

- Никаких значений вне токенов Air (палитра/шрифты/отступы — как в `tokens.css` v2).
- Один коралловый акцент на состояние экрана, всегда с текстом.
- Каждый лист заканчивается блоком «Открытые вопросы владельцу» — решения фиксируются прямо в листе.
- Утверждённый лист меняется только через владельца.
