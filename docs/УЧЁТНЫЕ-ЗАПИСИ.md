# Учётные записи — что сделать руками владельца

Код входа и регистрации написан и лежит в `frontend/functions/api/auth/`.
Он ждёт две вещи, которые может дать только владелец в панели Cloudflare:
**базу** и **ключ подписи сессий**. Пока их нет, вход честно отвечает
«учётные записи ещё не подключены», а урок по ссылке работает как работал.

## 1. База D1

Cloudflare → Workers & Pages → **D1 SQL Database** → *Create database*.

| Поле | Значение |
|---|---|
| Имя базы | `flamingo` |
| Регион | ближайший к ученикам |

Таблицу создавать руками не надо: первая же регистрация выполнит
`CREATE TABLE IF NOT EXISTS people (...)` сама.

## 2. Привязка базы к сайту

Cloudflare → Pages → проект `flamingo` → **Settings → Bindings → D1 database bindings**
→ *Add binding*:

| Поле | Значение |
|---|---|
| Variable name | `DB` |
| D1 database | `flamingo` |

⚠️ Имя переменной ровно `DB` — его знает код.

## 3. Ключ подписи сессий

Settings → **Environment variables** → *Add* (тип **Secret**, не plain text):

| Поле | Значение |
|---|---|
| Variable name | `SESSION_SECRET` |
| Value | длинная случайная строка |

Строку взять так (в Терминале):

```
openssl rand -base64 48
```

🔴 Этот ключ — единственное, чем подписана сессия. Сменить его можно в любой
момент, но все, кто вошёл, окажутся выйденными: старые куки перестанут
проверяться. Это не поломка, а именно то, что должно случиться.

## 4. Проверка

После первого выката с базой:

```
curl -s https://flamingo.plus/api/auth/me
```

- `{"person":null}` — база на месте, никто не вошёл. Так и должно быть.
- `{"error":"Учётные записи ещё не подключены…"}` — привязка не дошла,
  смотрите шаг 2.

Дальше на самом сайте: «Войти или завести учётную запись» → завести → выйти →
войти снова. Три шага, и они проверяют всё.

## Что сделано в коде и почему именно так

| Решение | Почему |
|---|---|
| Пароль хранится как PBKDF2-SHA256, 210 000 повторов, соль у каждого своя | По отпечатку пароль не восстановить. Соль у каждого своя, поэтому одинаковые пароли дают разные отпечатки, и общий список не помогает |
| Проверка сравнением постоянного времени | Иначе по скорости ответа подбирают отпечаток побайтно |
| «Почта или пароль не подошли» — один ответ на оба случая | Разные ответы превращают вход в способ узнать, кто у нас зарегистрирован |
| При неизвестной почте пароль всё равно считается впустую | Иначе «нет такой почты» отвечает заметно быстрее, и разница снова выдаёт список |
| Сессия — кука `HttpOnly`, `Secure`, `SameSite=Lax` | Её не прочитает ни один скрипт на странице: чужой скрипт не унесёт чужой урок |
| Пароль не короче восьми знаков, и сказано «четыре слова» | Длина надёжнее сложности; требование про «заглавную и цифру» гонит людей к `Password1!` |
