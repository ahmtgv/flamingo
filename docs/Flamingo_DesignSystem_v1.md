# Flamingo — Дизайн-система

**Версия:** 1.0
**Дата:** 13.06.2026
**Статус:** свод этапа 2 (токены, компоненты) и этапа 3 (прототипы). База для разработки веб-приложения.
**Парный документ:** `Flamingo_Brandbook_v1.md` — айдентика (логотип, палитра, типографика, иконки). Здесь — система: токены, компоненты, паттерны, прототипы.

---

## 1. Как пользоваться

Единый источник правды для UI. Иерархия зависимостей:

> Брендбук (решения) → `tokens.css` (значения) → компоненты (на токенах) → экраны и прототипы.

Главное правило: **компоненты ссылаются только на семантические токены**, никогда на примитивы и никогда на сырые значения (hex, px). Это позволяет менять тему, бренд и возрастной режим в одном слое без правок по всему коду.

---

## 2. Архитектура токенов

Двухуровневая, как в зрелых дизайн-системах:

1. **Примитивы** — сырые шкалы: `--fl-coral-500`, `--fl-warm-100`, `--fl-success-700` и т.д. Не используются в компонентах напрямую.
2. **Семантические алиасы** — роли: `--color-text`, `--color-accent-strong`, `--color-surface`, `--radius-control`. Только их потребляют компоненты.

Темизация и возрастной режим переключаются **атрибутами на корне**, переназначая семантику:
- `[data-theme="dark"]` — переопределяет цветовые алиасы.
- `[data-mode="kids"]` — переопределяет типографику, высоты контролов, тап-цели, радиусы.
- Комбинируются (тёмная + детская одновременно).

В проде токены живут на `:root` (`import './tokens.css'`). В прототипах-артефактах те же токены встроены и заскоуплены на `.fl-root`, чтобы артефакт был автономным — на перенос в проект это не влияет.

## 4. Дополнения к `tokens.css` (v1.1)

В ходе этапов 2–3 выявлены два дополнения — внести в `tokens.css`:

### 4.1 Размер чекбокса как токен
Чтобы чекбокс/радио масштабировались в детском режиме автоматически:
```css
:root{ --check-size:20px; }
[data-mode="kids"]{ --check-size:24px; }
```
В компоненте `.check .box{ width:var(--check-size); height:var(--check-size); }`.

### 4.2 Карта предметных цветов (детское расписание)
Цветовое кодирование предметов для младших классов:
```css
:root{
  --subj-math-bg:#f7edd7; --subj-math-fg:#8a5e0e; /* математика — янтарный */
  --subj-rus-bg:#e1ecf4;  --subj-rus-fg:#1f5780;  /* русский — синий */
  --subj-eng-bg:#e6f0e8;  --subj-eng-fg:#2e6b45;  /* английский — зелёный */
  --subj-read-bg:#ece6f2; --subj-read-fg:#5b3f86; /* чтение — фиолетовый */
  --subj-art-bg:#fbede6;  --subj-art-fg:#a23a1c;  /* рисование — коралловый */
}
```
Дарк-варианты предметных тинтов — отдельной задачей при включении тёмной темы в детских экранах.

## 5. Библиотека компонентов

Все компоненты — на токенах, с видимым focus-ring и состояниями. Эталон — артефакт `FlamingoStyleguide.jsx`.

| Компонент | Варианты / состояния |
|---|---|
| **Кнопка** | primary / secondary / ghost / danger × sm / md / lg; default, hover, active, focus, disabled, loading (спиннер) |
| **Поле ввода** | input / textarea / select (кастомный шеврон); default, focus, error, disabled; label + helper/error-текст |
| **Чекбокс / радио** | кастомные; checked, focus, disabled |
| **Свитч** | on / off / focus (для опций занятия и настроек) |
| **Бейдж** | success / warning / error / info / accent / neutral; опц. точка |
| **Карточки домена** | занятие (с кнопкой), курс (с прогресс-баром), ДЗ (со статусом) |
| **Таблица** | заголовок, hover строк, моноширинные числа, бейджи в ячейках |
| **Табы** | активная вкладка (коралловая линия), переключение контента |
| **Модалка** | оверлей, закрытие по клику-вне/Escape, header / body / actions |
| **Тосты** | success / info / error; всплывают справа снизу, авто-исчезновение |
| **Аватар** | sm / md / lg; со статус-точкой; инициалы |
| **Навигация** | сайдбар с активным пунктом (коралловая подложка) |
| **Доп. паттерны** | прогресс-бар, сегментированный переключатель, кнопки оценки 2–5, карточки расписания, дропзона загрузки, степпер сквозного flow |
| **Графики (SVG)** | живой CMF-график, отчётный график за сессию, бары по предметам, спарклайн |

Правила: иконка по умолчанию — цвета текста; коралл — только активное/интерактивное; семантические цвета — только семантическим элементам; тап-цель ≥44px (≥48 детский) даже при меньшей иконке.

## 6. Ключевые паттерны

### 6.1 Возрастная адаптация
Делится по природе (эталон — `flamingo_age_adaptation.html`):

| Автоматически (токены `[data-mode="kids"]`) | Контент-вариантом (решение на компонент) |
|---|---|
| Тело 16→19, интерлиньяж 1.6→1.75 | Иконки крупнее (44→56, `.icon-chip.lg`) |
| small/caption крупнее, h2/h3 на ступень | Короче подписи, меньше метаданных |
| Высоты контролов 40→48, тап 44→48 | Дружелюбные формулировки («Зайти на урок») |
| Радиусы control 10→14, card 16→20 | Цветовая кодировка предметов |
| Размер чекбокса 20→24 (`--check-size`) | Аватар учителя вместо текста, меньше элементов |

### 6.2 CMF и приватность «нода пользователя» — как UI-принцип
Везде, где задействована камера/внимание:
- Видимый индикатор **«Анализ на устройстве · видео не передаётся»** (иконка-щит) на экране занятия и при подключении.
- Калибровка лица перед входом в занятие (короткий прогресс), запрос камеры с пояснением.
- Живой график внимания обновляется локально; на экране-итоге — явная плашка **«на сервер ушли только обезличенные метрики, видео осталось на устройстве»**.
- В кабинете родителя анализ строится на обезличенных метриках — это проговаривается в UI.

### 6.3 Графики
Все графики — инлайновый SVG на токенах: заливка `--color-accent-subtle`, линия `--color-accent`, подписи моноширинным `--color-text-tertiary`, пунктирные опорные линии (среднее, перерыв) на `--color-border-strong` / `--color-warning`. Низкие значения (слабое место) подсвечиваются `--color-warning`.

## 7. Прототипы (этап 3) — инвентарь

Каждый — самодостаточный React-артефакт на токенах, кликабельные переходы, русские данные, переключатель темы (где уместно).

| Файл | Роль | Экраны | Ключевое |
|---|---|---|---|
| `FlamingoTeacherPrototype.jsx` | Преподаватель | TEACHER-001, 003, 004, 006, 010, 011 | конструктор курса/занятия, **drag-and-drop** занятий, оценивание |
| `FlamingoTeenPrototype.jsx` | Подросток | STUDENT-SR-001, 005, 006 + ДЗ | **живой CMF-график**, CMF-отчёт, сдача ДЗ, оценка |
| `FlamingoJuniorPrototype.jsx` | Младший / сравнение | STUDENT-JR-001, 003 | детский режим против подросткового, цветовое кодирование предметов |
| `FlamingoParentPrototype.jsx` | Родитель | PARENT-002, 005 | сводка по ребёнку, анализ CMF, инсайты и рекомендации |
| `FlamingoFlowsPrototype.jsx` | Сквозные сценарии | end-to-end | «ученик → занятие» и «преподаватель → ДЗ» со степпером |

**Честная граница прототипов:** видеопотоки — статичные заглушки (реальный WebRTC в прототипе не показывается); анимирован именно CMF-график как демонстрация взаимодействия; принцип on-device приватности отражён в UI.

## 8. Перенос в проект

- В проде создаётся `tokens.css` на `:root` (значения из разделов 3–4); компоненты импортируют его. Прототипы используют те же токены, заскоупленные на `.fl-root` — структура и имена идентичны.
- Компоненты из `FlamingoStyleguide.jsx` переносятся как библиотека UI; экраны прототипов — как заготовки страниц.
- Стек (из брифа): React, Redux Toolkit, Apollo Client. Иконки — `lucide-react`. Шрифты — IBM Plex Sans / Golos Text / IBM Plex Mono (подключение через `@fontsource`).
- Доступность: ориентир WCAG 2.1 AA (контрасты проверены в брендбуке), видимый focus-ring, тап-цели, `prefers-reduced-motion` (длительности обнуляются).
