# ПРИЁМКА — чем мерить, что экран сделан

Короткая карточка на каждый экран. Полное описание приборов — в `ПЕРЕДАЧА.md`, раздел 1.

---

## Механическая часть

Экран сделан, если выполнено всё пять пунктов.

**1 · Приборы молчат.**

```js
flAudit().verdict   // ни одного слова ДЕФЕКТ в восемнадцати приборах
```

Перед этим — **лист обязан ожить**: в `audit-run.html` колонка `alive` говорит, чем проверено
(ответ переключателя, реестр рунтайма), а `pageErrors` — молчала ли страница. Строка
«ЛИСТ НЕ ЗАПУСТИЛСЯ» отменяет все остальные клетки этой строки: по мёртвому экрану приборы
честно показывают ok, и это самый опасный зелёный (ПРАВИЛА 6.7е).

На мобильном листе (кадр помечен `data-mobile`) `pageScroll` не судится — вместо него
работает `mobileScroll`: одна вертикальная прокрутка листа, ни одной вложенной,
горизонтальной нет (ПРАВИЛА 8.6а).

**2 · Это верно во всех видах экрана:** светлая тема, тёмная тема, `data-mode="kids"`,
ширины 1280 и 1512 — и 390 × 844, если у экрана есть мобильный лист.

**3 · Это верно во всех состояниях, которые есть у экрана:** наполнено, пусто,
загружается, отказ, частичный отказ. Сдать только «наполнено» — не сдать экран.

**4 · Макет не прыгает.**

```js
const a = flAuditGeometry();   // в состоянии «загружается»
// переключить на «наполнено»
flAuditJump(a, flAuditGeometry())   // пустой массив
```

Место, которое обязано стоять на месте, помечается `data-geo="имя"`. Одно имя ставится и на
содержимое, и на его заглушку — так в коде записано «эти два занимают одно место».

**5 · Приборы исправны.**

```js
flAuditSelfTest()   // десять true
```

Без этого пункта первые четыре ничего не значат: зелёная проверка, которая ничего не
измеряет, опаснее её отсутствия.

## Живая часть

Урок вдвоём на настоящем продукте, владелец и ревьюер. Механическая часть не заменяет его,
а держит результат между уроками.

---

## Что приборами не мерится и смотрится глазами

| Что | На что смотреть |
|---|---|
| Переходы | панель выезжает, данные приезжают, пульты скрываются — макет не должен дёргаться и ничего не должно уезжать за край |
| Тексты | ошибки и пустые состояния: названа причина, названо уцелевшее, названо действие |
| Плохой канал | что видно, когда поток замолчал: слова, а не чёрный экран |
| Смысл цвета | коралловый только там, где горит; зелёный только там, где решено |
| Индикаторы состояния | переключатель, точка, галочка: видно ли включено, не угадывая по положению — в обеих темах, порог 3,0 (ПРАВИЛА 4.10) |
| Право у чужого источника | написано словами и видно классу |

---

## Порог, ниже которого не сдавать

- Текст на слайде урока и на проекторе — не мельче того, что читается издалека; служебные
  подписи туда не выводятся вовсе.
- Цель нажатия: одно действие в строке — вся строка, `--tap-min` (44, в kids 48); два и
  больше — кнопка, `--control-height-sm` (34, в kids 40).
- Контраст: 4,5 для мелкого текста, 3,0 для графики и крупного. Прозрачность считается.
- Отступы: только из `--space-*`, всё кратно 4, разных значений на экране не больше восьми.
- Прозрачностью тише не делают — ни текст, ни пульт с текстом (ПРАВИЛА 4.7).
- На телефоне: одно крупное действие на экран, полка вкладок и шапка стоят на месте,
  вложенных прокруток нет (ПРАВИЛА 9).
- У чужого источника названо три: что можно, чего нельзя и что будет, если он замолчит
  (ПРАВИЛА 8.10).
