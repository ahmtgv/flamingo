# Канва «Доска · холст»

Рабочие исходники листа. Канва опубликована ссылкой в переписке 30.08.2026.

Правки идут ОТСЮДА: меняем `.dc.html` (или генераторы), пересобираем канву заново
и публикуем по тому же адресу. Пересобирать из опубликованной страницы — крайний случай.

| Файл | Что это |
|---|---|
| `Main.dc.html` | комната, холст 100 %, пульт масштаба спит |
| `Otdalen.dc.html` | 45 %, пульт проснулся, «Показать всё» |
| `Priblizhen.dc.html` | 200 %, «Вернуть 100 %» |
| `Zahvat.dc.html` | чем берут холст: пробел, средняя кнопка, два пальца, Cmd+колесо, двойной щелчок |
| `VidA/VidB/VidC.dc.html` | три ответа на вопрос «чей вид ведёт» |
| `canvas.json` | раскладка, две страницы, заметки |
| `_parts.py` `_room.py` `gen1.py` `gen2.py` `_tokens.txt` | генераторы: комната собирается из токенов приложения |

Токены в `_tokens.txt` — копия `frontend/src/styles/tokens.css` на 30.08. Если токены
в приложении поменяются, копию надо обновить, иначе лист начнёт врать.
