# frontend

React + TypeScript + Vite. Экраны — реестр в `src/screens/Стенд.tsx`
(стенд: `/стенд?э=<имя>&чисто=1`, только `npm run dev`).

```bash
npm install     # только на маке, руками владельца — ../ПРАВИЛА-РАБОТЫ.md §9
npm run dev     # http://localhost:5180 (порт закреплён, --strictPort)
npm run guards  # караулы
npm run check   # типы + караулы + сборка + сборка-check
```

Порядок работы и границы куска — в корне: `../ПРАВИЛА-РАБОТЫ.md`, `../docs/ГРАНИЦА.md`.
