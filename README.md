# Flamingo

Онлайн-обучение. Проект начат **с нуля** 28–30.08.2026 и собирается кусками.
Старая версия снесена целиком — см. `CLAUDE.md` §6.

**Первый кусок: комната по ссылке.** Двое проводят занятие без регистрации:
видео, звук и общая доска. Что входит и — поимённо — что не входит: `docs/ГРАНИЦА.md`.

## Запуск

Порты закреплены за этим проектом: **фронт 5180, бэкенд 8080**. `--strictPort` не даёт
фронту тихо уехать на соседний порт и притвориться работающим.

```bash
# окно 1 — бэкенд
cd "/Users/piu/Claude/Projects/flamigo coworck/backend" && ./.venv/bin/python manage.py runserver 8080

# окно 2 — фронт
cd "/Users/piu/Claude/Projects/flamigo coworck/frontend" && npm run dev
```

Открывать **http://localhost:5180**. На первом экране — «Комната на двоих» и одно поле, имя.

Проверка, что бэкенд жив:

```bash
curl http://localhost:8080/api/room/healthz     # {"ok": true, "livekit": true}
```

Окружение бэкенда, если его нет:

```bash
cd "/Users/piu/Claude/Projects/flamigo coworck/backend"
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
```

## Что где

| Папка | Что внутри |
|---|---|
| `frontend/` | React + TypeScript + Vite. Экран входа и комната |
| `backend/` | Django. Один путь: подписывает токен LiveKit по коду комнаты |
| `docs/ГРАНИЦА.md` | что входит в первый кусок и что в него **не** входит |
| `docs/ПРАВИЛА-ДИЗАЙНА.md` | закон экранов |
| `docs/дизайн/` | токены, 24 листа дизайнера, приборы дизайна, знаки, брендбук |
| `docs/старое/` | летопись решений владельца до 30.08. Не задание — справка |
| `CLAUDE.md` | порядок работы над проектом |

## Проверки

```bash
cd frontend && npm run check     # типы + приборы с самопроверкой + сборка
```

Но **кусок несдан, пока путь не пройден вживую**: два окна, камера, звук, штрих на доске,
перезагрузка второго окна. Одиннадцать пунктов приёмки — в `docs/ГРАНИЦА.md` §5.
